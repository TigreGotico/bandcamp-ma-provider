# bandcamp-ma-provider

Bandcamp provider for [Music Assistant](https://music-assistant.io) — browse and stream Bandcamp releases, no login required.

## Install

```bash
pip install bandcamp-ma-provider
```

## Usage

```bash
mass-pm   # instead of music-assistant
```

Once running, the Bandcamp provider appears automatically in Music Assistant's provider list.

## Provider domain

| Domain | Description |
|---|---|
| `bandcamp_free` | Bandcamp track search and streaming |

## Requirements

- `music-assistant-plugin-manager`
- `py_bandcamp` — Bandcamp scraping client
